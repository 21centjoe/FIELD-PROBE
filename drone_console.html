WHAT THIS DOES

This encodes a file's raw bytes as black/white block patterns drawn frame-by-frame onto a canvas, then records that canvas as a video (.webm, via the browser's MediaRecorder — browsers can't natively mux MP4 client-side). Each frame carries a sequence number so the decoder can reject duplicates. This is a data container, not an executable one — playing the file normally just shows flashing black/white blocks. It's a real way to package a small file (a flight plan, a waypoint list, a config) as a single video artifact for archival or transfer; it is not a way to run code by playing a video.
