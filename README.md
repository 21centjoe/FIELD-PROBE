# FIELD-PROBE
This encodes a file's raw bytes as black/white block patterns drawn frame-by-frame onto a canvas, then records that canvas as a video (.webm, via the browser's Media Recorder — browsers can't natively mux MP4 client-side). Each frame carries a sequence number so the decoder can reject duplicates.  creats flight log in csv and simulation of drone drive flight movie that runs the drone using video as throughput to gpu (experimental)  try to figure out the system.
